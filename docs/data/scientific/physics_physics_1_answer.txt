答案：B
核心规律：同一根刚性杆上所有点，沿杆方向分速度大小相等。
两点沿杆分速度相等，但实际合速度大小不同，速度方向不相反；A 错误；
设 $C$ 点水平向左速度大小为 $v_{Cx}$，将 $C$ 点速度沿杆 $CB$、垂直杆 $CB$ 分解：垂直于杆分量：$v_C = v_{Cx} \cos 45^\circ$设顶端 $B$ 点竖直向上速度为 $v_B$，将 $B$ 点速度沿杆 $CB$、垂直杆 $CB$ 分解：沿杆分量：$v_{\text{杆 } B} = v_B \cos 45^\circ$如图所示，则有 $v_B = \sqrt{2} v_{Cx}$。$A$、$C$ 两点的间距每秒均匀缩短 $2\text{mm}$，则 $v_{Cx} = 1\text{mm/s}$可以求出 $B$ 点速度方向竖直向上，大小为 $2\text{mm/s}$；B 正确。
$C$ 点实际运动方向为水平向左，并非沿 $CB$ 杆向上；$C$ 点速度是水平速度，沿 $CB$ 杆仅为分速度，合速度方向水平，因此方向描述错误。C 错误。
$A$ 点固定，对地速度 $v_A = 0$；$C$ 点对地水平向左速度大小 $v_C$，$AC$ 缩短量为 $C$ 相对 $A$ 的水平位移 $\Delta x = 2\text{mm}$。相对速度定义：$v_{A \text{相对 } C} = v_A - v_C$，矢量上：$A$ 对地速度为 $0$，$C$ 水平向左，等价于 $A$ 相对 $C$ 水平向右，相对速度沿水平方向，相对位移大小等于 $AC$ 缩短量 $2\text{mm}$，相对速度大小对应水平方向差值，大小为 $2\text{mm/s}$（位移大小匹配速率）。几何上两点仅水平分离距离变化，竖直无相对位移，相对速度严格沿水平方向，大小为 $2\text{mm/s}$。D 错误。
